Solana MCP, WebMCP era

Docs intelligence, a built-in AI gateway, interactive UI, and storage — one MCP server, one deployment.

Connect

MCP endpoint: /mcp (Streamable HTTP). Try it with the MCP Inspector:

npx -y @modelcontextprotocol/inspector npx mcp-remote http://localhost:8080/mcp

What's inside

  • AI gateway in the server — solana_ask and ai_models run on the Neon AI Gateway; no client-side model key.
  • MCP Apps UI — render_docs_explorer renders results in a ui:// widget.
  • WebMCP — this page registers the server's tools with navigator.modelContext for browser agents (see /webmcp.js).
  • Auth — Neon Auth JWTs verified against the published JWKS; whoami is the profile tool, protected-resource metadata lives at /.well-known/oauth-protected-resource.
  • Storage — S3-compatible object storage with presigned URLs.
